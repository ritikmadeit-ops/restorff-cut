- **3 new library compositions, ported from trending open-source tools** (scout agent; `docs/restorff/SCOUT-2026-10-24.md`
  §5; each with example props and a `<name>.technique.json` for the director; credits in the file header, `NOTICE`
  and `third_party/<source>/`; library 56 → 59):
  - `gl-transition`: 27 gl-transitions shaders (MIT, @66a9759) in a WebGL2 host. Modes `cover` (wipe on, hold
    `hold` s, wipe off: centre it on a cut), `in`, `out`, `images` (picture A → B). The 16 shape wipes work in every
    mode; the 11 distortion ones (cube, swirl, pixelize, ripple, cross-zoom…) are refused outside `images` because

    `bun third_party/gl-transitions/extract.ts <clone> <sha>`.
  - `shader-bg`: full-frame animated backgrounds (`opaque`): Paper Shaders mesh-gradient / grain-gradient / warp /
    swirl (Apache-2.0, @71be015) in 40 looks (36 named presets from Remocn, MIT, @7aebcbe), `colors` takes a brand
    palette. Table regenerated by `bun third_party/paper-shaders/extract.ts …`. Costly on SwiftShader: grain-orb
    12–15 s per output second at 1080×1920 (MEASURED).
  - `caption-fx`: word-timed captions in 7 styles adapted from Remocn's caption components (MIT): highlight-box,

    solver and spring (no Remotion code).
  - Tested: `check` clean; every style / look / transition rendered at 540×960 and its contact sheet opened; one
    full-size render of each twice gave identical `framesHash`; `bun test` 218 pass, 0 fail. WebGL2 (not WebGL1) is

  - Bugs found by looking and fixed before landing: caption groups vanished (each group's end read the next group's

- **Animation libraries, offline, and our own GSAP-API runtime** (anim-runtime agent; `package.json` 0.2.0 → 0.3.0:
  new public API). Runbooks: `src/gsap-compat/README.md`, `vendor/README.md`; live table: `src/gsap-compat/STATUS.md`.
  - `src/gsap-compat/gsap.js`: MIT, clean-room implementation of the GSAP 3 API subset HyperFrames blocks use (174 of
    210 blocks, 237 of 238 components; survey counts in the worklog) — timelines, every position-parameter form,
    tweens/from/fromTo/set/call, CSS + transforms + SVG + attr + objects, autoRound, colours, complex strings,
    keyframes, stagger (grids too), eases (expo fitted to GSAP's observed curve), callbacks with GSAP's order and
    suppressEvents, `gsap.utils` (seeded
    random), CustomEase, MotionPath, Text/ScrambleText/DrawSVG/SplitText. No ticker: everything moves only on seek;
    same seek → same frame. GSAP itself is never shipped or read; behaviour was matched against real GSAP 3.14.2 as a
    black box in a scratchpad (`src/gsap-compat/oracle/`, GSAP outside the repo).
  - `<!-- rc-lib gsap three three-r147 lottie anime -->` markers (`src/libs.ts`): the renderer injects the libraries
    before any page script, in library and network-blocked custom renders; unknown names are errors; the libraries'
    sha joins the render hash only when used. `vendor/`: three.js 0.184.0 (+18 addons on `THREE.addons`) and 0.147.0
    (+ examples/js globals), lottie-web 5.12.2, Anime.js 4.5.0 — all MIT, 2.0 MB, NOTICE entries.
  - `src/gsap-compat/hf-protocol.js` (every page): HyperFrames' page protocol — paused timelines on
    `window.__timelines[id]` seeked (primed like HyperFrames, offset by `data-start`), `hf-seek` events with
    `waitUntil`, `window.__hfLottie` / `window.__hfAnime`, `window.__hf.buildReady`, `window.__hyperframes.getVariables()`.
    `runtime.js`: a page without `RC.composition` is driven by it; `render()` may return a Promise; `__hf.seek` may
    return one and `render.ts` awaits it before the capture. `custom.ts` accepts these pages (protocol `hf`).
  - `cdp.ts`: `--enable-unsafe-swiftshader` (WebGL 1 and 2 already work on ANGLE + SwiftShader; this keeps it when
    Chromium drops the automatic fallback). WebGPU is not available headless.
  - Oracle (114 eligible GSAP blocks, 6 frames each, real GSAP 3.14.2 vs ours, final code): of 110 comparable, 95
    render the same frames, 13 close, 2 differ by the metric but look the same (translate3d raster); 4 can't be
    compared (3 `<template>` files, 1 throws under real GSAP). Semantic probes: 80 of 99 answers identical.
  - `test/gsap-compat.test.ts` (47): timeline maths, positions, eases, stagger, keyframes, callbacks, determinism,
    seeded random, utils, libs, CSS/transform strings equal to GSAP's, the protocol, Three.js r184 + r147 + lottie +
    Anime in Chromium, bit-identical 4-tab renders (GSAP page and a Three.js page). Whole package: 583 pass, 0 fail.
  - Every render hash changes once (the runtime and hf-protocol are part of it): editor caches re-render on demand.

## 0.1.0 - 2026-10-20
First version.
- Renderer: Chromium headless shell over raw CDP (`src/cdp.ts`, Bun and Node) → transparent PNG per frame (seeked,
  `t = frame / fps`) → FFmpeg → WebM VP9 alpha (`yuva420p`, `alpha_mode=1`), ProRes 4444 `.mov`, or PNG frames.
  4 tabs with fixed frame assignment; ~0.9–1.3 s of rendering per second of 1080×1920 output (MEASURED).
- Page runtime (`src/runtime.js`): `RC.composition({ build, render })`, time object (`T`, `t`, `left`, `p`),
  9 easing presets, tween/progress helpers, seeded random, `fitText`, safe areas, 1080-grid unit, bundled fonts
  loaded from bytes before frame 0, CSS animations paused and seeked, `window.__hf` (HyperFrames page protocol),
  standalone browser preview.
- Contract (`CONTRACT.md`, `src/types.ts`, `src/params.ts`): typed params block, validation, standard params, lint
  for determinism hazards.
- Sentence nudges (`src/edits.ts`): slower/faster, bigger/smaller, bouncier/calmer/snappier, move up/down, colour,
  no exit.
- CLI: `render`, `still`, `look`, `probe`, `check`, `params`, `nudge`, `list`, `samples`.
- Starter library (8, fictional Halcyon content, each looked at): word-pop, badge-pills, big-word-punch, ui-card-pop,
  checklist, headline-wall, chart-grow, cover-story. Samples in `samples/`, each < 2,000,000 bytes.
- Matched to `docs/restorff/EFFECTS.md` acceptance bullets: word-timed `ticks` (checklist, FX-07, with "N of M"
  counter and progress bar, panel in the top of the frame) and `times` (badge-pills, FX-28); big-word punch starts on
  frame 0 so it can sit on the word onset (FX-22); 120 ms card stagger (FX-08); 80 ms letter stagger, 3 % inset,
  90 % wordmark (FX-16); `from: none` quiet pop (FX-27); `callout` pill at the peak (FX-10).
- Determinism: fixed frame-to-tab assignment, a browser context per tab, one raster thread, 2D transforms in
  `RC.set`; lint for `will-change` and `translate3d` (LEARNINGS §2).
- Tests: 46 (params, nudges, lint, determinism with 3 and 4 tabs, alpha, frame counts, ProRes, PNG, fast-vs-safe
  capture, chart values end at the input, error paths).
